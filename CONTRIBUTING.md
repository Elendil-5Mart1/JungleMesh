# Contributing

Thanks for your interest in JungleMesh!

- **Bug or idea?** Open an [issue](../../issues/new/choose). For security problems, see [SECURITY.md](SECURITY.md) instead.
- **Code:** fork, create a branch, open a pull request. Keep changes small and focused.
- Stack: Electron, React, Zustand, TypeScript, SCSS. Run `npm install`, then `npm run dev`; `npm run typecheck` must pass.
- Use two profiles on one machine to test peer-to-peer: `npm run dev` and `npm run dev:bob`.
- UI text goes through the translation files (English is the reference language); do not hard-code strings.
- Privacy first: never add telemetry, analytics or any request to a third-party server.

By contributing you agree that your work is released under the MIT license.
